# صور كاروسيل @qaf_of

هذا المستودع يستضيف صور كاروسيلات @qaf_of اليومية عشان Metricool يسحبها بروابط عامة وينشرها تلقائيًا.

- كل منشور له مجلد: `YYYY-MM-DD-tips` (حيلة الظهر) و `YYYY-MM-DD-news` (أخبار الليل)، فيه slide_01.jpg وما بعدها.
- المهام اليومية تحذف مجلدات الصور الأقدم من 7 أيام.
- مجلد `pipeline/` فيه أداة الرسم وخطوات المهمتين وذاكرة الحيل. الخط مشفّر، لا ترفع ملف خط مكشوف.
